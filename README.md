# 新西兰南岛包车之旅 · 线路讲解地图

面向潜在游客的交互式讲解页面，在地图上展示南岛线路：

- 经典线路：**中线 / 东线 / 西线 / 中线+东线环线**，可切换 **基督城或皇后镇出发**（自动反向或换起点）
- 单独行程：**米尔福德峡湾**（皇后镇出发 2天1晚）、**阿卡罗阿**（基督城一日游）、**凯库拉**（基督城出发 2天1晚）

- 途经地名与真实道路走向（OpenStreetMap + OSRM）
- 每一段的开车时长与里程
- 每站平均每人住宿费用（两人一间均摊）
- 推荐活动、价格、游玩时长（可勾选加入报价）
- 包车车型与报价：奔驰 SUV（2 人 + 2 个 28 寸行李，$800/天）、丰田 RAV4（2 人 + 2 个 28 寸行李，$700/天）、奔驰 V 级（5 人 + 5 个 28 寸行李，$1000/天）
- “讲解模式”：一键按站点自动飞行讲解

在线访问：https://huananchen-alt.github.io/nz-south-island-tour/

修改价格、活动或线路：编辑 `data.js` 即可。价格均为新西兰元 (NZD) 参考价。
